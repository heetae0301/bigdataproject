# 📊 KOSPI 기술적 신호 분석 시스템

KOSPI 지수의 기술적 분석과 Claude AI 기반 매매 신호 추천 시스템입니다.

## 🎯 프로젝트 소개

- **MACD, 이동평균선** 기술적 지표 분석
- **Claude AI**를 활용한 자동 분석
- **Streamlit** 웹 인터페이스
- **대화형 챗봇** 기능

## 📊 주요 기능

| 탭 | 기능 |
|----|------|
| **📊 대시보드** | 현재 시장 상태 |
| **📅 날짜 분석** | 선택한 날짜 분석 |
| **🤖 Claude AI** | 자동 분석 및 추천 |
| **💬 챗봇** | 대화형 Q&A |
| **⚡ MACD** | 상세 차트 |

## 🛠️ 설치 방법

```bash
pip install streamlit plotly anthropic pandas
```

## 🚀 실행 방법

```bash
streamlit run app.py
```

그 다음 `http://localhost:8501` 접속
