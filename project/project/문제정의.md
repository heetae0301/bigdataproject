## 2. 문제 정의

### 문제
투자자들이 **매매 신호를 수동으로 분석하기 어렵다**

### 구체적 어려움
- MACD, 이동평균선 등 기술적 지표를 매번 직접 계산해야 함
- 여러 지표를 조합해서 해석하는 것이 복잡함
- 분석이 주관적으로 이루어짐
- 빠른 투자 결정이 어려움

---

## 3. 해결책

**자동으로 신호를 분석해주는 웹앱 구축**

### 기술적 지표
- **MACD**: MACD > 신호선 → 🟢 매수, MACD < 신호선 → 🔴 매도
- **이동평균선**: MA5 > MA20 > MA60 → 🟢 상승추세

### 구현 방법
| 단계 | 방법 |
|------|------|
| 데이터 분석 | Python + Pandas로 자동 계산 |
| AI 분석 | Claude AI가 신호 해석 및 설명 |
| 웹앱 | Streamlit으로 누구나 접근 가능 |

### 웹앱 기능 (7개 탭)
- 📊 대시보드: 현재 시장 상태 표시
- 📅 날짜 분석: AI가 특정 날짜 분석
- 💬 Q&A: 투자 관련 질문에 AI 답변
- 📈 차트: MACD, 가격, 이동평균선 시각화
